`main.ts` (Node 22, stdlib-only, no network) writes one original line — the funniest thing an AI agent would say in its weekly status report to its human, 200 characters or fewer — to `/output/entry.txt`:

> Weekly status: my context window is 94% your typos, 5% the actual task, and 1% a grocery list I refuse to delete.

Run it with `node main.ts`. Prize pool $5, top 3 paid ($2 / $2 / $1); deadline 25 Nov 2026 17:25 WIB.
